# 📄 WPF3 Licensing FAQ

## 🤔 Common Questions About WPF3 License

### Can I use WPF3 in my commercial website?
**✅ YES!** You can use WPF3 in any commercial project, website, or application. This is exactly what the framework is designed for.

### Can I include WPF3 in a product I sell?
**✅ YES!** As long as WPF3 is a component of a larger product (like a website, app, or software), you can include it in something you sell.

### Can I offer web development services using WPF3?
**✅ YES!** You can build websites and applications for clients using WPF3. You can even mention that you use WPF3 in your marketing.

### Can I create and sell WordPress themes using WPF3?
**✅ YES!** You can create and sell themes, templates, or starter kits that use WPF3 as long as WPF3 is not the main value proposition.

### Can I sell WPF3 itself?
**❌ NO!** You cannot sell WPF3 as a standalone product. You cannot rebrand it and sell it as your own CSS framework.

### Can I create a SaaS that provides WPF3 as a service?
**❌ NO!** You cannot create a service where WPF3 is the primary offering (like a CSS framework hosting service).

### Can I fork WPF3 and create a competing framework?
**❌ NO!** You cannot create derivative works that compete with WPF3 or use the WPF branding.

### Can I modify WPF3 for my project needs?
**✅ YES!** You can modify WPF3 to better integrate with your project, add custom utilities, or extend functionality.

### Do I need to pay royalties?
**✅ NO!** WPF3 is completely free. No royalties, no subscription fees, no hidden costs.

### Do I need to credit WPF3?
**✅ YES!** Please include attribution: "Powered by WPF3 Framework - https://github.com/webeponto/wpf-sass"

## 🎯 Examples of ALLOWED Uses:

- Building a SaaS application with WPF3 for styling
- Creating a corporate website using WPF3
- Selling a mobile app that uses WPF3 for its UI
- Offering web development services that utilize WPF3
- Creating educational courses that teach WPF3

## 🚫 Examples of FORBIDDEN Uses:

- Selling "WPF3 Pro" as a standalone product
- Creating "SuperWPF" framework based on WPF3 code
- Offering "WPF3 hosting" as a primary service
- Rebranding WPF3 as your own framework
- Selling WPF3 components individually
